# LiveRoom

Локальное AI-приложение с двумя режимами: ролевой чат с персонажем и интерактивная визуальная история с выбором действий и иллюстрациями.

## Требования

- Windows (для BAT-файлов запуска) и Node.js 18 или новее.
- [Ollama](https://ollama.com/) с моделью `hf.co/mradermacher/Katarau-9B-ru-RP-nsfw-GGUF:Q4_K_M` (можно изменить через `OLLAMA_MODEL`).
- ComfyUI с установленным чекпойнтом `lustifySDXLNSFWSFW_v20.safetensors`.

## Запуск

1. Запусти `start-comfyui.bat` и дождись, пока ComfyUI станет доступен.
2. Запусти `start-site.bat`. Скрипт проверит Node.js, запустит сервер и подождёт его готовности перед открытием браузера.
3. Открой `http://127.0.0.1:4173/`, если браузер не открылся автоматически.
4. На главной странице нажми «Проверить снова», чтобы проверить доступность Ollama и ComfyUI.

Сервер по умолчанию привязан к `127.0.0.1` и не предназначен для публикации в интернете без дополнительной аутентификации и настройки безопасности.

## Проверка

После установки Node.js выполни:

```sh
npm test
```

Smoke-тесты запускают локальный сервер на отдельном порту и проверяют главную страницу, основные страницы приложения, health endpoint и недоступность служебных файлов через HTTP. Они не заменяют интеграционный тест генерации: для проверки реального ответа модели Ollama и ComfyUI должны быть запущены.

## Модели и данные

- LUSTIFY SDXL v2.0 (`lustifySDXLNSFWSFW_v20.safetensors`) — основной чекпойнт ComfyUI для генерации персонажей и сцен.
- Katarau 9B в Ollama ведёт ролевой чат и интерактивную историю.
- Диалоги, память, настроение, отношения и сессии истории сохраняются локально в браузере.
- Изображения генерируются локально через ComfyUI. Текущий текстовый пайплайн не гарантирует точное сохранение одного лица между разными изображениями; для этого понадобится отдельная интеграция с референсным изображением (например, совместимый IP-Adapter/FaceID workflow).
