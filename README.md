# LiveRoom

Локальный AI Chat с двумя режимами: RP-чат с персонажем и интерактивная визуальная история с выбором действий и иллюстрациями.

## Запуск

1. Запусти `start-comfyui.bat` — ComfyUI нужен для генерации изображений.
2. Запусти `start-site.bat` — откроется LiveRoom на `http://127.0.0.1:4173/`.
3. Для диалога должна быть запущена Ollama с моделью `hf.co/mradermacher/Katarau-9B-ru-RP-nsfw-GGUF:Q4_K_M`.

## Данные и модели

- LUSTIFY SDXL v2.0 (`lustifySDXLNSFWSFW_v20.safetensors`) — основной чекпойнт ComfyUI для фотографий персонажей и сцен. Основан на SDXL 1.0; автор отмечает поддержку SFW и NSFW и рекомендует 30 шагов, CFG 4–7, DPM++ 2M SDE.
- Исходный SDXL (`sd_xl_base_1.0.safetensors`) оставлен в папке чекпойнтов как резервный. Источник LUSTIFY: https://civitai.com/models/573152/lustify-sdxl-nsfw-checkpoint
- Katarau 9B в Ollama ведёт RP-чат.
- Интерактивная история принимает завязку, описание главного героя и состав участников; ход сюжета и варианты действий генерируются через Ollama, иллюстрации — через ComfyUI.
- Диалоги, факты памяти, настроение и уровень отношений хранятся локально в браузере отдельно для каждого персонажа.
- Видео-маршруты, экран клипов и неиспользуемые WAN/SAM/Comfy-LLM веса удалены.
