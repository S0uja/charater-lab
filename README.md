# LiveRoom

Локальное AI-приложение: ролевой чат и интерактивная визуальная история.

## Требования
- Windows и Node.js 18+.
- [Git for Windows](https://git-scm.com/download/win) для обновления проекта из монитора.
- [Ollama](https://ollama.com/) с моделью `hf.co/mradermacher/Katarau-9B-ru-RP-nsfw-GGUF:Q4_K_M` (переопределяется через `OLLAMA_MODEL`).
- ComfyUI с чекпойнтом `lustifySDXLNSFWSFW_v20.safetensors`.

## Запуск компонентов отдельно
1. **AI-сервисы:** запусти `start-ai.bat`. Он проверит Ollama, запустит её при необходимости и затем запустит/переиспользует ComfyUI через `start-comfyui.bat`.
2. **Сайт:** отдельно запусти `start-site.bat`. Скрипт проверит Node.js, запустит локальный сервер и откроет браузер.
3. **Монитор:** запусти `start-monitor.bat`. Он постоянно проверяет сайт, ComfyUI и Ollama каждые 2,5 секунды. Нажми `S`, чтобы запустить только службы со статусом DOWN, `R`, чтобы выполнить `git pull --ff-only` в папке проекта, или `Q`, чтобы выйти. После успешного pull монитор сравнит версии до и после обновления и подскажет, что именно делать: обновить вкладку сайта, перезапустить сайт, ComfyUI, Ollama или сам монитор. Он не перезапускает все сервисы автоматически — только показывает рекомендации по изменённым файлам.
4. Адреса по умолчанию: сайт `http://127.0.0.1:4173/`, Ollama `http://127.0.0.1:11434`, ComfyUI `http://127.0.0.1:8188`.
5. Для обновления через монитор нужна установленная Git for Windows и настроенный remote в локальном клоне. Команда не делает автоматический merge: если локальная ветка разошлась с удалённой или есть конфликтующие изменения, Git сообщит об ошибке.
6. ComfyUI Portable должен быть распакован в ожидаемую папку проекта. Сервер сайта привязан к localhost и не предназначен для публикации в интернете без дополнительной защиты.

## Проверка
Запусти `npm test` после установки Node.js. Автотесты проверяют страницы, API-валидацию и контролируемые ошибки при недоступных Ollama/ComfyUI. Они не заменяют проверку генерации с реально запущенными AI-сервисами.

## Модели и данные
- LUSTIFY SDXL v2.0 — чекпойнт ComfyUI для изображений.
- Katarau 9B в Ollama — текстовая модель чата и истории.
- Диалоги и состояние истории хранятся локально в браузере.
- Текущий пайплайн не гарантирует точную идентичность лица между разными изображениями; для этого нужна интеграция с референсным изображением, например IP-Adapter/FaceID.

## Автоматические проверки

После установки Node.js 18+ запусти из папки проекта:

```bat
node --check server.js
node --check monitor.js
npm test
```

Тесты запускают сервер на временном локальном порту и проверяют главную страницу, HEAD-запросы, запрет неподдерживаемых методов, закрытость служебных файлов, обработку некорректного URL, ответ health endpoint при недоступных AI-сервисах, валидацию API чата и истории, пустые запросы генерации, неизвестные ID задач, защиту пути изображения от traversal, проверку имён участников и контролируемые ответы при недоступных Ollama/ComfyUI. Также сервер сохраняет задачу изображения, если ComfyUI временно не может ответить на запрос очереди, чтобы клиент мог повторить проверку. Ollama и ComfyUI для этих тестов не нужны. GitHub Actions запускает синтаксические проверки и тесты при каждом push в `main` и при pull request.
